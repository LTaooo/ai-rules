# 开发与凭证规则

- 不读取用户填写的 `.env` 、 `.env.*`、`databases.json`；`.env.example` 仅含虚构配置，可以读取。
- 不打印环境变量、数据库连接字符串、参数和查询数据，不通过修改程序或执行脚本间接输出凭证。
- 全部数据源配置（含密码）存于 Windows 凭据管理器，目标名前缀 `database-query.`；不存在任何配置文件，不读取、打印或推断凭据内容。
- `init` 是交互式向导，需要交互终端，由用户自行运行；agent 不代替执行，也不模拟键盘输入。
- 测试只使用虚构凭证、虚构凭据目标名及本目录内独立测试数据，不连接用户生产数据库，不创建真实凭据。
- 所有产物保存在本项目目录；不要提交真实凭证和数据库文件。
- 修改后运行 `npm run check`，不得跳过只读安全测试。
- 不执行 `git commit`，不创建分支。
